## 🧭 命令面与契约

- **agent-help 覆盖矩阵与 live 命令树精确对齐**：157 行，0 条幽灵命令、0 条遗漏；
  新增 `TestCoverageMatrixMatchesCommandTree` 契约测试守护
- **13 处 `--agent-help` 标题修正**为真实命令路径：`gitee api`、`repo star star/unstar`、
  `repo watch watch/unwatch`、`repo protect protect/unprotect`、`issue label` 6 个子命令
- **`gitee help reference`**：去掉重复的 `issue label` 子树（根因是重复 AddCommand），
  并把 `version` 纳入输出
- **参数契约统一**：所有支持 `--repo` 的命令补齐 `-R` 短参；不接受位置参数的命令
  改为 `cobra.NoArgs`/`ExactArgs` 严格报错，不再静默忽略
- **分组命令不再静默 exit 0**：`repo star/watch/protect/tag/file/commits/collaborator`
  带位置参数时返回非 0 并提示正确全路径（如 `gitee repo star star owner/repo`）
- **`-o` 只接受 `table|json`**：`-o csv` / `-o yaml` 等非法值直接报错（此前静默退回 table），
  并从 flag 帮助与 `help formatting` / `help environment` 中移除 csv 宣称
- **13 个环境变量真实生效**：`GITEE_HOSTNAME`、`GITEE_API_URL`、`GITEE_OUTPUT`、
  `GITEE_VERBOSE`、`GITEE_TIMEOUT`、`GITEE_LIMIT`、`GITEE_PAGINATE`、
  `GITEE_NO_EXTENSIONS`、`NO_COLOR`（以上为新增默认值支持），以及原本就支持的
  `GITEE_TOKEN`、`GITEE_ALIASES_FILE`、`GITEE_EXT_DIR`、`BROWSER`；
  非法整数/布尔值硬报错；`help environment` 与实现双向锁定
- **`search repos` 空结果说明**：Gitee 仓库搜索接口当前对大多数查询返回空，CLI 会在
  stderr 提示原因并建议 `gitee repo list --owner <owner>`
- 顺带修复：`--limit` 在非 `--paginate` 时被忽略的历史 bug；`--verbose` 的 HTTP trace
  改到 stderr（不再污染 `-o json` 的 stdout）

## ⚠️ 行为变更（升级注意）

1. `-o csv` 不再被接受（此前静默输出 table）：脚本如果依赖 `-o csv`，改用 `-o json`。
2. 分组命令的旧扁平写法（`gitee repo star owner/repo`、`repo protect master`）现在会
   **报错**而不是打印帮助并 exit 0：改用 `gitee repo star star owner/repo`、
   `gitee repo protect protect master`。
3. 不接受位置参数的命令（多数 `list`）传多余参数会报错（此前静默忽略）。
4. `gitee help reference` 现在包含 `version`，且不再重复 `issue label` 子树——解析该输出
   的脚本可能需要按唯一路径去重逻辑调整（本应更简单）。
